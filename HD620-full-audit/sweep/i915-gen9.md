## Top 15 candidates

Ranked by expected value for an HD 620 laptop (performance, power, correctness). Each is a starting point for a follow-up test, not a confirmed bug.

1. **GuC/HuC off by default on Gen9** (intel_uc.c:34): no firmware-side power management runs unless enable_guc is set, so test whether forcing HuC loading works on this GPU and what it changes at idle.
2. **Media power-gate hysteresis of 250** (intel_rc6.c:190): sets how long the media well stays on; tuning it changes idle and video-playback power.
3. **RPS down-timeout of 50 ms** (intel_rps.c:1276): governs how quickly the GPU clock steps down, a direct power-versus-responsiveness knob.
4. **SKL-only RC6 wake-rate-limit branch** (intel_rc6.c:150): KBL takes the generic branch, so confirm that KBL gets the intended RC6 wake-rate setting.
5. **PSR2 size cap of 3640x2304** (intel_psr.c:1558): panels larger than this cannot use PSR2 and lose its power savings.
6. **DC9 entry and exit are not verified** (intel_display_power_well.c:707, 725): the TODOs mean DC9 state is never checked, a possible source of display power or correctness issues.
7. **DMC program never disabled on SKL/KBL uninit** (intel_display_power.c:1668): the uninit path never disables the DMC program (TODO), so its effect on package power is unverified.
8. **Object-level preemption disabled per context** (intel_workarounds.c:536): the WA turns off 3D object-level preemption, so Gen9 contexts run without object-level preemption unless userspace opts in.
